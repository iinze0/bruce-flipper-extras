# Themes

Place theme repositories and community theme packs here when you fetch them locally.

Suggested local layout:
- external/anonimoKali-Bruce-Themes/
- external/Ghoststrats-GhostStrats-Bruce-Themes/

Notes:
- Keep images small; a height around 140 px works well for T-Embed screens.
- The main repo ignores downloaded content in `external/`.
